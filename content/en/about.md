# About

**Toolbox Notes** is where I write about the small programs I build to make repetitive work a little less tedious.

It isn't tied to one topic — any tool I made because I needed it can show up here. Each post covers:

- the problem the tool was built to solve
- what it does and how to use it
- what went wrong along the way, and what I learned

This blog is available in English and Korean. Use the language button at the top of the page to switch.
