Every so often a task comes along that is just annoying enough to repeat — copying numbers between sheets, checking the same pages every morning, renaming a pile of files. At some point it becomes faster to build a small tool than to keep doing it by hand.

**Toolbox Notes** is where I write those tools down.

## What you'll find here

The topics won't be limited to one field. If I built something because I needed it, it can end up here. For each tool I'll try to cover:

- **The problem** — what was slow, error-prone, or tedious before
- **What the tool does** — the main features, with screenshots
- **How to use it** — enough detail that you could try the same approach
- **What I learned** — the mistakes and surprises along the way

## Who writes this

I've been programming for more than ten years, and for over five of those I've also run online stores on Amazon, Coupang and Naver Smart Store — sourcing, listings, ads, inventory and customer service. Running stores is where most of my "annoying enough to automate" tasks come from, so many of the tools here started as fixes for my own daily routine. More background is on the [About](../../about/) page.

## How I build these tools

A few rules I try to follow for everything posted here:

- **Official routes only.** When a tool touches a platform like Amazon, it uses the platform's official API, not scraping or shared logins.
- **Your data stays with you.** Tools run on your own computer where possible, and credentials are stored encrypted locally.
- **Small and focused.** Each tool does one job well instead of trying to replace a whole suite.
- **Real screens, real numbers.** Walkthroughs use actual screenshots from my own accounts, with private details masked.

If something in a post is out of date or doesn't match what you see, email [toolbox@toolboxnotes.com](mailto:toolbox@toolboxnotes.com) and I'll fix it.
